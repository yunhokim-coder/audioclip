# AudioClip

유튜브 공개 영상에서 원하는 시간 구간을 MP3로 저장하는 한국어 웹앱입니다.

## 외부 서버에 배포 — Render

웹앱과 변환 API를 한 서버에서 실행합니다. PC에 Docker를 설치할 필요가 없습니다.

1. 이 코드 전체를 별도의 GitHub 저장소에 올립니다. `render.yaml`과 `Dockerfile`은 저장소 맨 위에 있어야 합니다.
2. Render에 로그인하고 **New → Blueprint**에서 해당 저장소를 연결합니다.
3. 서비스가 **Free**인지 확인합니다. 이 설정은 유료 플랜을 자동 선택하지 않습니다. Render의 계정/사용량 정책은 대시보드에서 확인하세요.
4. 배포가 끝나 `Live`가 되면 서비스의 웹사이트 주소를 엽니다.
5. Render 서비스의 **Environment**에서 자동 생성된 `API_TOKEN` 값을 확인합니다. 채팅이나 GitHub에 붙여넣지 마세요.
6. 웹앱의 **서버 연결 설정**에서 기본 서버 주소를 유지하고 연결 키에 그 값을 입력합니다.
7. 본인 소유 또는 다운로드 권한이 있는 짧은 공개 영상부터 실제 변환을 테스트합니다.

`API_TOKEN` 없이 Render에 배포하면 서버가 시작되지 않습니다. 상태 확인용 `/healthz`만 인증 없이 열리고 변환/파일 API는 연결 키를 요구합니다. `PORT`는 호스팅 환경에 맞춰 자동 적용됩니다. UI는 기본적으로 현재 사이트의 API를 사용합니다.

원래 ChatGPT Site 화면에서 사용하려면 설정의 변환 서버 주소에 Render가 반환한 HTTPS 주소를 입력합니다. CORS에는 원래 Site 주소가 등록되어 있습니다.

**배포 성공과 유튜브 다운로드 성공은 별개입니다.** 데이터센터 네트워크에서 유튜브가 미디어 요청을 제한할 수 있습니다. 기존 테스트에서는 영상 정보는 조회됐지만 실제 미디어 다운로드가 실패했습니다. 새 서버에서 실제 변환을 확인하기 전에는 정상 작동을 보장하지 않습니다. Free 서비스의 휴면/대역폭/메모리 제한도 적용됩니다. 대용량이나 장시간 작업 전에 작은 구간부터 테스트하세요. 요금제 업그레이드는 자동으로 수행하지 않습니다.

## 내 PC에서 실행 — 선택 사항

1. Docker Desktop을 설치하고 실행합니다.
2. 전체 소스 압축을 풀고, 그 폴더에서 터미널을 엽니다.
3. `docker compose up --build -d`를 실행합니다.
4. 브라우저에서 **http://localhost:8000**을 엽니다.
5. 유튜브 영상 링크를 입력 → 불러오기 → 시작·종료 시간 → MP3 만들기 → 다운로드.

예: 2시간짜리 플레이리스트 **영상** 안에서 `35:10`부터 `39:25`까지만 저장할 수 있습니다. 여러 영상으로 구성된 재생목록 URL 대신 개별 영상 링크를 사용하세요. 영상 미리보기에서 재생 버튼을 눌러 선택 지점을 확인할 수 있습니다. 미리보기는 유튜브의 임베드 허용 여부 및 브라우저 정책에 따라 제한될 수 있습니다.

종료: `docker compose down`
업데이트: `docker compose build --no-cache` 후 `docker compose up -d`

## Docker 없이 실행

Python 3.10+, FFmpeg, Node.js 22+가 필요합니다.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

## 사이트와 변환 서버

배포된 정적 사이트는 UI이며, FFmpeg와 yt-dlp를 실행하는 변환 서버를 별도로 연결해야 다운로드가 작동합니다. Docker로 실행하면 UI와 API가 같은 서버에서 제공되어 별도의 연결 설정 없이 사용할 수 있습니다. 정적 사이트 자체가 YouTube 미디어를 다운로드하거나 변환하지 않습니다.

외부 서버에 배포하려면 이 Docker 이미지를 실행할 수 있는 호스트와 HTTPS 역방향 프록시가 필요합니다. `.env` 파일을 만들고 다음 변수를 지정하세요.

```
API_TOKEN=충분히-길고-무작위인-개인-연결키
ALLOWED_ORIGINS=https://yunho-audio-clip.linenfoam8.chatgpt.site,https://실제-변환서버-주소
```

`compose.yaml`은 기본적으로 **127.0.0.1에만** 포트를 노출합니다. 외부 연결 시 HTTPS 프록시를 통해 노출하고, 연결 키를 지정하세요. 사이트의 서버 연결 설정에 HTTPS 주소와 키를 입력합니다. 서버 주소는 localStorage, 키는 sessionStorage에 저장됩니다. CORS 설정은 인증을 대신하지 않습니다. 개인 사용용이며, 여러 사용자에 대한 파일 격리나 계정 시스템을 제공하지 않습니다.

## 동작과 제한

- YouTube URL을 검증한 뒤 고정된 youtube.com 영상 주소로 정규화합니다.
- yt-dlp `--download-sections`와 FFmpeg로 선택 구간을 MP3로 변환합니다. 소스에 따라 더 많은 원본 데이터를 읽을 수 있으며, 잘리는 위치에 인코딩 단위의 작은 차이가 있을 수 있습니다.
- 출력 비트레이트: 128 / 192 / 320 kbps. 원본 음질 이상의 복원은 하지 않습니다.
- 영상 최대 12시간, 1회 저장 구간 최대 4시간, 변환 최대 20분, 동시 처리 2개.
- 변환 파일은 임시 디렉터리에 저장되고 작업 생성 1시간 후 주기적으로 삭제됩니다. 컨테이너 종료 시에도 사라집니다.
- 실시간 방송, 비공개 영상, DRM 및 인증이 필요한 콘텐츠는 지원하지 않습니다.
- 유튜브가 데이터센터 IP나 자동 요청을 차단하면 다운로드가 실패할 수 있습니다. 서버의 yt-dlp를 업데이트하거나 로컬에서 실행해 보세요. 쿠키 수집, 로그인 우회 기능은 없습니다.
- 서버 재시작 후 이전 작업은 복원되지 않습니다. uvicorn은 기본 단일 프로세스로 실행하세요.
- 본인 소유 또는 다운로드 권한이 있는 콘텐츠에 사용하세요.

## 검증

`pip install -r requirements-dev.txt` 후 `python -m unittest discover -s tests -v`

URL 검증, 범위 검증, 연결 키 인증, API 작업 생성과 다운로드, 실패 처리, 실제 FFmpeg 변환 파일의 길이를 검증합니다. 외부 유튜브 연결 성공은 서버 네트워크와 유튜브 정책에 따라 달라지므로 보장하지 않습니다.

구간 다운로드 구현 근거: https://github.com/yt-dlp/yt-dlp#usage-and-options
